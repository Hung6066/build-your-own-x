# AI Agent 7 Harnesses

> Version: 1.0 - June 2026

Hope.Agent now exposes a machine-checkable harness layer at:

- `GET /v1/harness/status`
- `GET /v1/harness/governance`
- `GET /v1/harness/context-provenance`
- `GET /v1/harness/workflows/debug/{workflow}`
- `GET /v1/learning/eval/metrics`

Smoke test:

```powershell
.\tests\hope-7-harness-validation.ps1
```

## 1. Context Harness

Implemented:

- Conversation history, memory, skill retrieval, user traits, conversation compression, clinical context.
- Context budget via `AgentRuntimeOptions.MaxContextChars`.
- Context provenance stored in `audit_logs.PayloadJson.contextManifest`.
- Context provenance can be queried by conversation/correlation id.
- Retrieval rail filters unsafe memory before injection.

Key proof:

- `agent.run` audit payload includes `contextManifest`.
- `/v1/harness/status` returns `contextHarness`.
- `/v1/harness/context-provenance?conversationId={id}`

## 2. Tool Harness

Implemented:

- Tool registry, MCP-style schemas, direct invoke endpoint.
- Tool sandbox timeout and argument/output size limits.
- Autonomous action worker executes tools through the same sandbox executor.
- JSON schema validation enforces required fields, basic types, enums and `additionalProperties=false`.
- Tool approval policy for write/critical tools.
- Tool RBAC via `ToolApproval:ToolRoleAccess`.
- Production default-deny for tools missing RBAC config via `AllowUnconfiguredToolAccess=false`.
- Database persistence tools and outbound Email/Slack/Zalo channels.

Key proof:

- `/v1/tools`
- `/v1/security/approvals`
- `/v1/harness/status.toolHarness`

## 3. Orchestration Harness

Implemented:

- Main `AgentOrchestrator`.
- Adaptive routing, skills, reflection, judge, shadow comparison.
- Workflow dispatch for scheduling, summary, reminder, audit.
- Controlled autonomy workers: daily review, action executor, AGI-like goal loop.
- Machine-readable DAG specs under `Orchestration:Dags`.
- Workflow debug endpoint returns DAG, Mermaid graph, and recent decision trace.

Key proof:

- `/v1/harness/governance.orchestrationDags`
- `/v1/harness/workflows/debug/clinical_autonomy`
- `.\tests\hope-autonomy-levels-3-4-5.ps1`

## 4. Evaluation Harness

Implemented:

- Eval cases, eval runs, trend, leaderboard, Elo tournament.
- Standard metrics endpoint:
  - `taskSuccessRate`
  - `hallucinationRate`
  - `toolCallAccuracy`
  - `faithfulness`
  - `latencyP95Ms`
  - `costPerSuccessUsd`
- Level 5 eval gate/readiness.

Key proof:

- `GET /v1/learning/eval/metrics`
- `GET /v1/harness/status.evaluationHarness`

## 5. Security Harness

Implemented:

- Prompt shield, output shield, PHI redaction, prompt egress guard.
- Retrieval rail against indirect prompt injection.
- SSRF guard, DPoP, idempotency, rate limiting, security headers.
- Tool RBAC and approval.
- Suspicious SQL-like payload guard in agent chat.
- Red-team regression suite covers prompt injection, critical tool misuse and malformed tool args.

Key proof:

- `.\tests\hope-7-harness-validation.ps1`
- `.\tests\hope-redteam-regression.ps1`
- `/v1/harness/status.securityHarness`

## 6. Governance Harness

Implemented:

- Responsible role, approver role, access roles, escalation role per agent family.
- Endpoint/table access matrix under `Governance:AccessMatrix`.
- Approval SLA/escalation by risk under `Governance:ApprovalSla`.
- Human approval endpoints.
- Decision ledger and autonomous action queue.
- Hash-chained audit sink.
- Level 5 readiness/eval/drift records.

Key proof:

- `/v1/harness/governance`
- `/v1/autonomy/decisions`
- `/v1/autonomy/actions`
- `/v1/security/approvals`

## 7. AgentOps Harness

Implemented:

- OpenTelemetry meter `Hope.Agent`.
- Token, cost, latency, tool error, prompt block, approval, judge, shadow and KG counters.
- Alert rules in `AgentOps:AlertRules`.
- Version fingerprint stored in `audit_logs.PayloadJson.versionFingerprint`.
- Autonomy decisions include version fingerprint in evidence payload where they are generated by the suggestion loop.
- Level 5 drift/readiness endpoints.

Key proof:

- `/v1/harness/status.agentOpsHarness`
- `audit_logs.PayloadJson.versionFingerprint`
- `POST /v1/autonomy/level5/drift/detect`
- `GET /v1/autonomy/level5/readiness`
